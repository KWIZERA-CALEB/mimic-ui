THEME AUTHORING

Three starting points.
Your own finish.

A theme describes each component’s visual design, markup, and interaction choices. Theme implementations should be separately authored so they can feel meaningfully different.

Classic

Balanced proportions and familiar patterns for a clear, flexible baseline.

Studio

A more expressive direction with room for stronger hierarchy and personality.

Minimal

Reduced visual noise and focused behavior for interfaces that need to stay quiet.

Where component source goes

registry/themes/<theme>/<framework>/<component>/

Framework targets are React, Angular, Vue, Svelte, and React Native. These folders are currently authoring placeholders. Add a component only after its implementation is complete and ready to copy.
