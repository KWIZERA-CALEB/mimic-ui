The Classic theme is the first complete component set. It currently supports React, Angular, Vue, and React Native, with TypeScript sources that the CLI can convert to JavaScript.

Classic

A balanced palette built around teal and deep blue. Browse all 20 components in the component catalog.

React styling

React components use Tailwind CSS 4 utilities and use Radix UI for accessible compound controls. The CLI lists required packages but never writes a global stylesheet.
