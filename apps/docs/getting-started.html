GETTING STARTED

Make yourself at home.

Pick a framework, language, and theme. Mimic writes a small config in your project and copies components into the folder you choose.

1. Initialize

node path/to/mimic_ui/packages/cli/src/index.js init

The setup prompts for React, Angular, Vue, or React Native; TypeScript or JavaScript; a theme; and an install preference.

2. Browse the Classic theme

Open the component catalog to search categories, view examples, switch framework and language snippets, and copy add commands.

3. Copy a component

node path/to/mimic_ui/packages/cli/src/index.js add button

The CLI copies source files and reports framework dependencies. It prompts before replacing existing files, and does not install packages or modify global styles.

React styling

React sources use Tailwind CSS 4 utilities plus Radix UI, Lucide, CVA, clsx, and tailwind-merge. The CLI lists these dependencies. Add them to your project and configure your own theme tokens as needed.

Angular JavaScript

JavaScript output uses Angular decorators at runtime, so it is intended for JIT projects. Choose TypeScript for Angular AOT builds.

Configuration

{
  "theme": "classic",
  "framework": "react",
  "language": "typescript",
  "components": "src/components/ui",
  "installMode": "individual"
}
