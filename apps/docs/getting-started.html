GETTING STARTED

A small first step.

Mimic UI is currently a foundation for a copy-first component library. Set up the project now; add component source as your theme implementations take shape.

1. Initialize

npx @mimic-ui/cli init

Choose React, Angular, Vue, Svelte, or React Native. Then choose Classic, Studio, or Minimal and set whether you intend to add components one by one or all together.

2. Check the registry

npx @mimic-ui/cli list

The MVP registry starts empty. The CLI will tell you when there are no published components. It does not install CSS, packages, or framework code into your project.

3. Add a component

npx @mimic-ui/cli add button

Once a component is implemented and registered, the CLI copies it to the configured component folder. Update mimic.json to change your destination paths and selected theme.

Configuration

{
  "theme": "classic",
  "framework": "react",
  "components": "src/components/ui",
  "utils": "src/lib/mimic.ts"
}

The utils field is reserved for future helper generation. No helper file is created in this MVP.
