# Component registry

Classic is the first complete theme. Author its framework-native TypeScript sources under `themes/classic/<framework>/typescript/components/`. JavaScript files are generated by the CLI from TypeScript sources; this keeps behavior and fixes aligned across language choices.

Frameworks: `react`, `angular`, `vue`, and `react-native`. `scripts/sync-registry.mjs` copies theme sources into the CLI package. The CLI metadata lives in `packages/cli/templates/registry.json`.

React components were adapted from the component source supplied for this project. They use Tailwind CSS 4 utilities and declare their package needs in the registry. Vue styles are scoped, Angular styles are component-scoped, and React Native styles use `StyleSheet`. No global CSS is copied into consumer projects.

Other theme and framework folders remain placeholders until their implementations are ready.
